# Aula de patrones

Una página educativa estática para explorar visualmente ideas sobre datos y modelos en un entorno subterráneo imaginario. La interfaz está escrita en español con HTML, CSS y JavaScript sin dependencias de aplicación.

## Uso

Abre `index.html` en un navegador. En el panel visual, cambia entre dos representaciones conceptuales: una tendencia esquemática y una red de relaciones ilustrativa. Los dibujos son fijos y no procesan datos.

La sección Holmberg–Persson presenta el método solo como tema de lectura y discusión, sin fórmulas ni contenido de diseño.

## Límites educativos

- Todos los ejemplos son ficticios y se identifican como tales.
- Las ilustraciones son abstractas, no tienen escala ni dimensiones físicas.
- La página no incorpora datos de campo, cálculos, predicciones, recomendaciones ni parámetros operativos.
- La explicación de Holmberg–Persson es conceptual: no incluye ecuaciones, entradas, resultados ni instrucciones para dimensionar o planificar una voladura.
- No debe usarse para diseñar, planificar ni ejecutar una operación.

El proyecto sirve únicamente como material introductorio para conversar sobre la lectura crítica de patrones y las limitaciones de los modelos.
